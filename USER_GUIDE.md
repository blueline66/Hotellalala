# User Guide

## Запуск програми

```bash
dotnet run --project src/HotelBooking.Console
```

## Меню

### 1. Показати номери
Відображає список доступних номерів.

### 2. Створити бронювання
Дозволяє створити нове бронювання.

### 3. Показати бронювання
Виводить список усіх бронювань.

### 4. Strategy Pattern
Показує приклад розрахунку цін.

### 5. LINQ-аналітика
Показує LINQ-запити та статистику.
