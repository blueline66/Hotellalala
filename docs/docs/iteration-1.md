# Підсумки Ітерації 1 (Передача в Лабораторну 35)

## Що вже працює
- Доменна модель номерів та бронювань (із захистом від неправильних дат).
- Перший вертикальний зріз: успішне бронювання номера через консоль та блокування подвійного бронювання.
- In-memory збереження даних.
- Написано 5 юніт-тестів, які успішно проходять.

## Які артефакти є в репозиторії
- Бачення проєкту (`vision.md`), беклог (`backlog.md`), діаграми класів та послідовності.
- Налаштований Solution із шарами: Domain, Application, Infrastructure, Console, Tests.

## Що буде розширюватися на Lab 35
1. Заміна In-Memory бази на реальне збереження у файл (JSON).
2. Додавання функції перегляду всіх бронювань та їх скасування.

## Класи, підготовлені під розширення
- Абстрактний клас `Room` (дозволяє легко додавати нові класи номерів за допомогою поліморфізму).
- Інтерфейси `IRoomRepository` та `IReservationRepository` (дозволяють підмінити базу даних, не чіпаючи логіку).
