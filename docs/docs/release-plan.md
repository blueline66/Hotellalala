# Release Plan

## Технічні борги (Technical Debt)

### Concurrency
У разі одночасного доступу до reservations.json можливі конфлікти запису.
У майбутньому можна реалізувати lock-механізм або перейти на базу даних.

### UI
Консольний інтерфейс має обмежені можливості.
У наступних версіях планується створення Web API або GUI.

### Validation
Валідація введених даних реалізована частково.
Потрібно додати більш надійну перевірку дат та користувацького вводу.


## Стабілізація (Hardening)

- Додано XML-коментарі до основних сервісів.
- Усунено дублювання коду в Program.cs.
- Оптимізовано LINQ-запити.
- Покращено структуру проєкту.
- Додано fault handling через try/catch.
