# Система бронювання готелю (Hotel Booking System)

## Опис проблеми
Готелям потрібен зручний інструмент для управління номерами, щоб уникати подвійних бронювань на одні й ті ж дати.

## Цільові користувачі
Адміністратор готелю (ресепшен).

## Основні сценарії
1. Бронювання номера (перевірка доступності та створення запису).
2. Перегляд списку всіх бронювань.
3. Скасування бронювання.

## Нефункціональні вимоги
1. Читабельність коду (дотримання SOLID).
2. Захист від некоректних даних (дати виїзду не можуть бути раніше дати заїзду).
3. Легкість розширення для додавання нових типів номерів.

## Обмеження 1-ї ітерації (Lab 34)
Дані зберігаються лише в оперативній пам'яті (in-memory). Немає бази даних і графічного інтерфейсу (тільки консоль).
